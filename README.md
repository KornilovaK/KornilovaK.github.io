# Сайт Ekaterina Kornilova

Персональный сайт ML-инженера для GitHub Pages. Сайт статический: для него не нужны установка зависимостей и сборка.

## Посмотреть на компьютере

Откройте `index.html` двойным щелчком в браузере. Или в терминале из этой папки выполните:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Чтобы остановить сервер, нажмите Ctrl+C в терминале.

## Как менять сайт

- `index.html` — тексты, ссылки и порядок разделов. Откройте файл в любом редакторе, например VS Code. Найдите нужную фразу, замените её и сохраните файл. Обновите страницу браузера.
- `style.css` — оформление: цвета, размеры, отступы и адаптация для телефона. Основные цвета заданы в начале файла в `:root`.
- `favicon.svg` — значок во вкладке браузера.

Чтобы добавить проект, найдите в `index.html` раздел `id="work"`, скопируйте один из блоков `<article class="project ..."> ... </article>` и измените компанию, даты, название, описание и теги. Не публикуйте конфиденциальные сведения работодателя.

Контакты, местоположение и даты также находятся в `index.html`. Перед публикацией проверьте актуальность и публичность сведений.

## Как опубликовать изменения

В терминале из папки репозитория:

```bash
git status
git add -A
git commit -m "Create personal portfolio website"
git push origin HEAD
```

Если Git попросит авторизацию, войдите в GitHub. В репозитории на GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку, в которую отправлены изменения (обычно `main`), и папку `/ (root)`, затем нажмите **Save**. Через несколько минут сайт появится по адресу https://kornilovak.github.io/. При следующих изменениях достаточно снова выполнить `git add`, `git commit` и `git push`; настройки Pages обычно повторять не нужно.

Если страница не обновилась, проверьте вкладку **Actions** и статус публикации в **Settings → Pages**, подождите несколько минут и обновите страницу с очисткой кэша. Если используются другие ветки или в репозитории уже настроен другой способ публикации, проверьте текущие настройки перед их изменением.

Шрифты загружаются из Google Fonts; без сети браузер использует системные шрифты.
